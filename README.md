# SITES

Projeto desenvolvido em **HTML** e **CSS**, com foco na criação de páginas web estruturadas e visualmente organizadas.  
O objetivo é aplicar boas práticas de marcação e estilização para construção de sites.

## Tecnologias Utilizadas
- **HTML5** → Estrutura e organização do conteúdo  
- **CSS3** → Estilização, cores, tipografia e layout das páginas  

## Objetivos do Projeto
- Criar páginas web responsivas e bem estruturadas  
- Praticar conceitos de design e usabilidade  
- Aplicar organização de código para fácil manutenção
